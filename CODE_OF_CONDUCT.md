# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be welcoming, respectful and constructive. Harassment, insults, discrimination and publishing other
people's private information are not tolerated in issues, discussions, pull requests or any other project space.

**Reporting:** contact the maintainer [@andriagv](https://github.com/andriagv) privately (for example, through a
private security advisory on this repository), or open an issue if it is not sensitive. Reports are handled
confidentially. The maintainer may remove content and block participants who break these rules.
